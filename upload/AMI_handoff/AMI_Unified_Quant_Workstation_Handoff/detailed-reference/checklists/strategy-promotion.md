# Strategy promotion checklist

- [ ] Strategy has a unique permanent ID and semantic version.
- [ ] Hypothesis, rationale, exact rules and finite variants were registered before comparison.
- [ ] Instrument universe and data windows were fixed before looking at results.
- [ ] Point-in-time data integrity and closed-bar availability proven.
- [ ] Data manifest, input hashes and experiment run IDs recorded.
- [ ] Costs include commissions, fees, spread, slippage and gap/fill assumptions.
- [ ] Baseline and no-trade comparator included.
- [ ] All trials, including failed variants, counted.
- [ ] Chronological development/validation and locked holdout protocol respected.
- [ ] Walk-forward and sample sufficiency gates passed.
- [ ] Net expectancy, profit factor, drawdown and uncertainty reported.
- [ ] MAE/MFE, exit behavior, regime/session and instrument breakdowns reviewed.
- [ ] Cost/slippage sensitivity and parameter neighborhood robustness tested.
- [ ] No holdout tuning or data leakage observed.
- [ ] Forward paper results reconciled and operational errors reviewed.
- [ ] Independent reviewer and owner decision recorded.
- [ ] Live execution remains separately gated and is not implied by strategy promotion.
