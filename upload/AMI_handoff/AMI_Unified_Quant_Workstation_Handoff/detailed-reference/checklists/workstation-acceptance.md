# Workstation acceptance checklist

- [ ] Existing Market View behavior and API/state call paths mapped before modifying.
- [ ] Four charts visible simultaneously in desktop layout.
- [ ] Each chart independently selects canonical instrument and timeframe.
- [ ] Layout presets 1/2/4/6 work and persist after reload.
- [ ] Chart labels expose venue, product type, contract, provider and data freshness.
- [ ] Right sidebar exposes P&L, fees, drawdown, exposure, risk and strategy status with definitions.
- [ ] Lower dock exposes Intelligence, System Map, Events and Research.
- [ ] Market/Intelligence/System mode changes preserve workspace context.
- [ ] System node inspector exposes version, health, dependencies, permissions and errors.
- [ ] Decision lineage can be traced from trade plan back to source events.
- [ ] Stale, disconnected, fixture, empty, loading and failure states tested.
- [ ] No sample chart/data is mistaken for real-time market data.
- [ ] UI does not authorize risk, create real orders or enable live mode.
- [ ] Keyboard use, focus order and accessible labels verified.
- [ ] UI remains responsive under chart updates and unavailable model workers.
