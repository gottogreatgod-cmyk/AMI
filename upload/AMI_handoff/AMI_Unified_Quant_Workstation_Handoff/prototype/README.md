# AMI workstation prototype

Open `index.html` directly in a modern desktop browser. No server, dependencies, API key, network connection or installation is required.

All chart paths, prices, market changes, portfolio metrics, strategy results, event timestamps and module statuses are synthetic illustrative fixtures. They are not live prices, not real P&L, not validated strategy results and not operational health. The prototype cannot connect to brokers or submit orders.

The prototype demonstrates the intended dense workstation: watchlist rail, multi-chart canvas, 1/2/4/6 layout presets, market/intelligence/system modes, metrics/risk sidebar, topology dock, searchable instruments/modules and clickable node inspector. It is a UX reference, not production React code.
